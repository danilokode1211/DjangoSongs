# INFO.txt
1. Este proyecto usa Django 4.2
- manage.py runserver → iniciar servidor de desarrollo
- manage.py migrate → aplicar migraciones
- manage.py createsuperuser → crear administrador
- requirements.txt → dependencias del proyecto

1 . Crear entorno virtual (si no existe):
   python -m venv .venv (este nombre puede variar)

2. Activar entorno virtual:
   - Windows:
     .venv\Scripts\activate
   - Mac / Linux:
     source .venv/bin/activate

3. Instalar dependencias:
   pip install -r requirements.txt

4. Desactivar entorno virtual:
   deactivate

## Dependencias principales
- Django==4.2.x
- djangorestframework==3.20.x

(Otras librerías que uses…)

## Comandos útiles de Django
- python manage.py runserver
  → Inicia servidor de desarrollo
    
  → Apaga el servidor con: 
    ctrl+c
- python manage.py makemigrations
  → Detecta cambios en los modelos y prepara migraciones

- python manage.py migrate
  → Aplica migraciones a la base de datos

- python manage.py createsuperuser
  → Crear superusuario para el admin

- python manage.py shell
  → Abrir consola interactiva de Django

- pip freeze > requirements.txt
  → Actualizar lista de dependencias

## Tips y buenas prácticas:

- Siempre activar `.venv` antes de trabajar.
- Hacer commits frecuentes con mensajes claros.
- Mantener `requirements.txt` actualizado al agregar librerías.
- Consultar INFO.txt como guía rápida de comandos.
